# koe-clean

ナレーション録音のノイズを、ブラウザの中だけでまとめて除去するアプリ。

**開く:** https://ryogotamura2-ai.github.io/koe-clean/

## 使い方

1. 録音ファイル（WAV・MP3・M4A など）をまとめてドロップする。フォルダごとでもよい
2. 自動で順番に処理される。終わったものから「処理前／処理後」を切り替えて聞き比べられる
3. 「まとめて保存」を押す。Chrome・Edge は保存先のフォルダを選んで直接書き出し、
   ほかのブラウザは ZIP でダウンロードする

- 書き出しは **WAV・48kHz・24bit**、ファイル名は「元の名前_clean.wav」
  （同じ名前があれば上書きせず「(2)」を付ける）
- **効きの強さ**は 最大／強め／ふつう／弱め。あとから変えても処理し直さずに反映される。
  声がこもって聞こえるときは弱める
- ステレオの録音は左右それぞれ処理する（左右が同じ中身なら1本として扱う）

## 音声はどこにも送られない

処理はすべてブラウザの中で行う。通信するのは、最初にノイズ除去の部品（約23MB）を
このサイトから読み込むときだけで、外部のサービスには何も送らない。

## 対応ブラウザ

Chrome・Edge がおすすめ。Safari 16.4 以降・Firefox 114 以降でも動く作りだが、
動作を確かめたのは Chromium だけ。

M4A（AAC）は Chrome・Edge・Safari なら読める。Chromium の一部の版はライセンスの都合で
AAC を読めないので、読めないときは WAV に変換して入れる。

## 中身

| ファイル | 役割 |
|---|---|
| `index.html` / `style.css` / `app.js` | 画面、順番の処理、試聴、保存 |
| `lib/wav.js` / `lib/zip.js` | WAV（24bit）の書き出し、無圧縮の ZIP |
| `dfn3/dfn3-worker.js` | ノイズ除去を裏で動かす処理役（Web Worker）。並列に最大4つ動かす |
| `dfn3/dfn3-core.js` | DeepFilterNet3 の前後の計算。公式の libDF（Rust）から移植した |
| `dfn3/models/dfn3_stateful.onnx` | モデル。公式の ONNX 版3ファイルを1つにまとめ、途中の状態を受け渡せるようにしたもの。**重みは変えていない**。作り方は `tools/` |
| `dfn3/vendor/ort/` | onnxruntime-web 1.30.0（npm の公式配布物と同一のファイル） |

長い録音は 2.5 秒ずつ区切って処理する。区切りごとに途中の状態を引き継ぐので、
結果は一度に処理した場合とビット単位で一致し、メモリの使用量も長さによらず一定に保てる。

## 品質の確かめ方（2026-09-27）

| 確かめたこと | 結果 |
|---|---|
| Python 版（PyTorch の DeepFilterNet3）の出力と比べる。48kHz の録音 | 差 -147dBFS。24bit で保存するときの丸め誤差だけ |
| 同じく 44.1kHz の録音 | 差 -87dBFS。48kHz への変換方法（ブラウザと soxr）の違いで、聞き取れない |
| 強さ「ふつう」と、Python 版の `atten_lim_db=12` | 差 -149dBFS |
| 区切って処理した結果と、一度に処理した結果 | 完全に一致 |
| 速さ（4コアの作業環境・Chromium） | 53 秒の録音 2 本を、並列に約 3.5 秒（読み込みから完了まで） |

## モデルを選んだ経緯

4つのモデル（DPDFNet の小・大、DeepFilterNet3、MossFormer2）で実際の録音を処理して
聞き比べ、DeepFilterNet3 を選んだ。経緯は `ryogotamura2-ai/projects` リポジトリの
`app/koe-clean/` にある。

## 手元で動かす

このフォルダで `python3 -m http.server` を起動し、http://localhost:8000/ を開く。
ファイルを直接開く（`file://`）と、処理役を起動できないので動かない。
